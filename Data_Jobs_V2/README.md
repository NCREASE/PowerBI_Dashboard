# Data Job Market Analysis Dashboard/Power BI (Version 2.0)

![Dashboard Page 1](/Images/Project2.png)

## Introduction
Navigating the data job market can be a complex endeavor, with information dispersed throughout various sources. This dashboard (V2.0) is specifically designed for **job seekers, career transitioners, and individuals seeking new opportunities** to alleviate the confusion. By utilizing a comprehensive dataset of 2024 data science job postings, which includes detailed information on job titles, salaries, and geographic locations, this project provides a streamlined, single-page interface that facilitates the exploration of critical market trends and compensation insights.

## Technical Skills Utilized

* **🎨 Dashboard Design:** Crafting an intuitive and visually appealing repor layout.
* **⚙ Power Query ETL:** Performing data cleaning, shaping, and transformation.
* **🔗 Data Modelling:** Building efficient data models with relationships (Star Schema principles).
* **🧮 Dax Fundametals:** Creating calculations and aggregations to derive key insights.
* **📊 Visualizations Utilized:**
    * **📈 Core Charts:** Column, Bar, Line, and Area charts for comparisons and trends.
    * **🗺 Map Charts:** For displaying geospatial data.
    * **🔢 Cards:** To highlight key performance indicators.
    * **🎚 Tables:** For presenting detailed, tabular information.
    * **📉Chart Variety:** Selecting from common and uncommon chart type for effective storytelling.
* **🎚 Interactive Features:**
    * **🗄 Slicers:** Enabling dynamic, user-driven data filtering
    * **⚪ Buttons and Bookmarks:** For streamlined navigation and managing report views (including Drill-Through)

## Dashboard Overview
This second iteration of the dashboard combines everything into one clear page. It is designed to give job seekers easy access to important market insights.

 ![Dashboard Page 1](/Images/Project2.png)

This page is your main resource for understanding the data job market. It showcases key performace indicators (KPIs) like **Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary** (based on job percentage or count). It also allows you to compare **Salaries across different Job Titles**, providing a clear overview of the market.

## Conclusion

This updated dashboard (Version 2.0) shows Power BI's capability to transform large job posting data into an effective tool for career analysis. It helps **Job Seekers, Career Transitioners, and Job Swappers** by allowing them to easily filter and explore key market insights on one page. This enables them to make well-informed decisions about their next career steps.
